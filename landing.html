Kenapa Versi Web Recommended

Tentang Aplikasi Web Ini

Versi web ringan, cepat, dan tidak perlu instalasi rumit. Berikut keunggulan dan cara memakainya.

1

Tanpa akun, tanpa server

Semua data latihan dan riwayat tersimpan di perangkatmu sendiri. Tidak ada pendaftaran, tidak ada yang terkirim ke mana pun.

2

Bisa dipakai offline

Setelah halaman pertama selesai dimuat, seluruh aplikasi bisa dibuka tanpa internet — cocok untuk daerah dengan sinyal terbatas.

3

Install seperti aplikasi biasa

Bisa ditambahkan ke layar utama HP dan Start Menu di PC, lalu dijalankan dalam mode layar penuh tanpa address bar.

4

Selalu versi terbaru

Tidak perlu mengunduh pembaruan. Aplikasi otomatis mengambil versi terbaru begitu kamu membuka lagi.

5

Ringan di HP lama

Total ukurannya hanya sekitar 300 KB, jauh lebih ringan dibanding aplikasi native yang bisa berukuran ratusan megabyte.

6

Fitur lengkap

Ujian berwaktu, teka-teki silang, kuis kilat, pembahasan soal, riwayat, sampai deteksi kecurangan saat ujian tetap ada.

Cara Install di Perangkatmu

Di PC / Laptop Buka di Chrome atau Edge, lalu klik ikon Install di address bar. Selesai — aplikasi masuk ke Start Menu.
Di Android Buka di Chrome, pilih menu tiga titik, lalu pilih Install app. Ikon muncul di layar utama.
Di iPhone Buka di Safari, tekan tombol Share, lalu pilih Add to Home Screen.
